= Building Block View
:page-layout: default

Stem is a compiler pipeline (source → AST → output) with **two lowering
backends** off a shared parse stage, plus helper, runtime, and command-line
modules.

This page is a map, not the full design. The detailed rationale lives in the
project notes (`notes/`): _Native AST Compilation Pipeline_, _Portable Stem
Bytecode_, _Parser-Tokenizer Fusion Decision_, _Native Backend Strategy_, and
_Rust Host API for Native Backend_.

== Front end (shared)

[cols="1,3"]
|===
| Module | Responsibility

| `Stem`
| Public API: compile-time macros (`function_from_string/5`, `function_from_file/5`) and runtime `compile_string/2` / `compile_file/2`. Runtime *evaluation* lives in `Stem.Unsafe` (see xref:architecture:09-architecture-decisions.adoc[ADR-0002, ADR-0004]).

| `Stem.Parser`
| Scans source into structural tokens (line/column metadata) and matches blocks, expanding partials into a `Stem.AST`. The tokenizer is fused into the parser — there is no separate `Stem.Tokenizer` module (_Parser-Tokenizer Fusion Decision_).

| `Stem.Expression`
| Translates the contents of each tag into the structured expression form.

| `Stem.AST`
| Node type definitions for the template tree; `to_wire/1` serialises the pre-expansion AST (`stem-ast/v1`).
|===

== Lowering backends

[cols="1,3"]
|===
| Module | Responsibility

| `Stem.Compiler`
| Lowers the AST into quoted Elixir (the BEAM backend).

| `Stem.Bytecode`, `Stem.Bytecode.VM`
| Lowers the AST into a versioned, capability-aware portable program (`stem-bc/v1`) and renders it on a small VM — output byte-identical to the compiled backend (_Portable Stem Bytecode_). `VM.inspect_at/3` snapshots the render context for the playground's Context Inspector.
|===

== Runtime, helpers, and surfaces

[cols="1,3"]
|===
| Module | Responsibility

| `Stem.Runtime`
| Resolves assigns when a compiled template runs; truthiness and context scoping.

| `Stem.Transformers`, `Stem.Builtins`, `Stem.Escaping`
| Helper registry + invocation (capability-grouped), the built-in stdlib, the `each` loop primitive, and escape modes (HTML-escape by default).

| `Stem.DSL`, `Stem.Contract`, `Stem.Formatter`, `Stem.Sigil`, `Stem.Config`
| Declarative macros, compile-time assign contracts, the `mix format` plugin, the `~STEM` sigil, and project-config defaults.

| `Stem.CLI`, `Mix.Tasks.Stem`
| The command-line renderer and the Mix task.

| `Stem.Native`, `Stem.Conformance`
| The bridge to the native engine and the cross-backend conformance harness.
|===

== Native engine (`native/`)

A from-scratch renderer in Rust/WASM consuming the same `stem-bc/v1` bytecode,
byte-for-byte against the Elixir reference. Crates: `stem_compile` (parser +
compiler, with a `nimble_parsec_rs`-based lexer/expression front end),
`stem_native` (the VM, the typed Rust API, and the wasm-bindgen browser exports
`compile`/`render`/`parse_ast`/`inspect_at`/`version`), `stem_macros` (the
`stem!` compile-time macro), and `stem_examples`. See _Native Backend Strategy_
and _Rust Host API for Native Backend_.
