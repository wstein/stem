= Building Block View
:page-layout: default

The compiler is a four-stage pipeline supported by helper, runtime, and command-line modules.

== Top-Level Structure

[cols="1,3"]
|===
| Module | Responsibility

| `Stem`
| Public API: compile-time macros (`function_from_string/5`, `function_from_file/5`) and runtime compile/eval APIs.

| `Stem.Tokenizer`
| Scans source into structural tokens with line and column metadata.

| `Stem.Parser`
| Matches blocks and expands partials into a `Stem.AST`.

| `Stem.AST`
| Node type definitions for the template tree.

| `Stem.Compiler`
| Lowers the AST into quoted Elixir.

| `Stem.Expression`
| Translates the contents of each tag into Elixir source.

| `Stem.Runtime`
| Resolves assigns when a compiled template runs.

| `Stem.Helpers`, `Stem.Helpers.Sanitize`, `Stem.Builtins`
| Helper registry and invocation, built-in sanitize helpers, and the `each` loop primitive.

| `Stem.DSL`, `Stem.CLI`, `Mix.Tasks.Stem`
| Declarative macros, the command-line renderer, and the Mix task.
|===
