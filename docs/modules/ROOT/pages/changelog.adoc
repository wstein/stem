= Changelog
:page-layout: default

Notable changes to Stem, newest first. This project follows
https://semver.org/[Semantic Versioning]; during the `0.x` series a breaking
change bumps the minor version.

For step-by-step upgrade instructions, see xref:manual:migration.adoc[Migration Guide].

== 0.3.0

_2026-05-26._ Additive engine and tooling work, plus the breaking changes
since `0.2.0` (no compatibility shim for any of the breaking items).

=== Added

* *Native engine introspection* — two new primitives, implemented in Rust and
  mirrored in the Elixir reference: `parse_ast` returns a template's
  pre-expansion AST (`stem-ast/v1`, with `{{> name}}` kept as `partial` nodes),
  and `inspect_at` re-runs the VM to snapshot the render context at a given
  source span. Elixir counterparts: `Stem.Parser.parse_ast/2` and
  `Stem.Bytecode.VM.inspect_at/3`.
* *Recoverable-error accumulation* — `Stem.Parser.parse_all/2` (and the native
  `compile_to_wire_all`) collect every recoverable parse error in one pass,
  each attributed to the file it occurred in, instead of stopping at the first.
  The fail-fast `parse/2` is unchanged.
* *Native browser surface* — the Rust/WASM engine is exposed via wasm-bindgen
  (`compile`/`render`/`parse_ast`/`inspect_at`/`version`), replacing the
  hand-rolled linear-memory marshalling. A `stem!` compile-time macro compiles
  template literals to bytecode at Rust build time.
* *Web playground* — a CodeMirror-based IDE in `native/web/` with an inspector
  suite (diagnostics dock, bytecode disassembly, context inspector, partial
  dependency graph + Syntax Tree) and find-in-files search & replace.

=== Changed

* *Contextual references use the `@` prefix* — `@this` (current context, valid
  everywhere — at the root it is the render assigns, so `{{@this.name}}` works
  outside blocks), `@parent` (immediate enclosing context), and `@root` (the
  render assigns) replace the Mustache/Handlebars `this`, `{{.}}`, and `../`
  forms, which are removed. `@first`/`@last` join `@index`/`@index1`/`@key`,
  and all five are a compile error outside an `#each`. `items.[2]` indexes a
  list, and a missing key or out-of-range index now renders empty rather than
  raising.
* *Pipe syntax* — the pipeline separator is now a single `|` with
  space-separated prefix arguments; the `transformer(arg, …)` paren-call form is
  removed in favour of `()` grouping (`{{name | truncate 20}}`,
  `{{default (upcase name) "anon"}}`).
* *Built-in arity is validated at render time* — a built-in called with the
  wrong number of arguments raises a uniform, byte-identical error on both the
  BEAM and the native engine instead of silently truncating arguments or
  aborting the engine.
* *`eval` transformer* — now renders a full Stem template string (braces
  included), not a bare inner expression.
* *Single-quoted literals* are now string literals, equal to their
  double-quoted form (`{{default missing 'N/A'}}`). They previously compiled to
  Elixir charlists, emitting a deprecation warning and rendering incorrectly.
* *Renamed* `Stem.Runtime.is_truthy/1,2` to `Stem.Runtime.truthy?/1,2`.

=== Removed

* *Elixir-expression fallback* — the `allow_elixir_expressions` option, the
  `--allow-elixir-expressions` CLI flag, and the `mix stem.audit` task are
  removed. Templates are structured-only; an unrecognised expression raises
  `Stem.SyntaxError`.
* *Computed getters* — zero-arity function assigns (BEAM) and the native
  `$getter` host hook are removed. Resolve values before rendering.

=== Reserved

* The boolean operators `||` and `&&` are reserved for a future release and are
  now refused at compile time.
