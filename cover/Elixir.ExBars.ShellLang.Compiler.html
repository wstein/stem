6 # Compiles a ShellLang AST into a real BEAM module.
7 #
8 # Unlike a wrapper that re-interprets the AST at runtime, this compiler
9 # emits Elixir AST that mirrors the program structure:
10 #
11 # * Top-level statement order becomes BEAM code in `main/0`.
12 # * `if/else` becomes a real Elixir `if`.
13 # * `fn name(args) { body }` becomes a real `defp __sh_<name>/2`
14 # in the generated module (statically callable when invoked by
15 # literal name).
16 # * Variable lookup, watchpoint bookkeeping, and pipeline execution
17 # are delegated to `Runtime` helpers — they need to remain dynamic
18 # because variable names are looked up by string.
19 #
20 # The interpreter (`Runtime.execute/1`) remains the default execution path
21 # used by `ShellLang.run!/1`. Compilation is invoked explicitly via
22 # `ShellLang.compile_module!/2`.
